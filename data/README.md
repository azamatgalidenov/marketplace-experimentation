# Data

Nothing in `data/raw/` or `data/processed/` is committed to Git. Both are regenerated by
the pipeline.

| Folder | Contents | Produced by |
|---|---|---|
| `raw/` | The 9 Olist CSV files plus the downloaded zip | `uv run python -m marketplace_analytics download` |
| `processed/` | `marketplace.duckdb`, the analytical warehouse | `uv run python -m marketplace_analytics build` |

## Source: Olist Brazilian E-Commerce Public Dataset

- URL: <https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce>
- Licence: CC BY-NC-SA 4.0 (non-commercial use, attribution to Olist)
- Content: about 99k real, anonymised orders placed on the Olist marketplace in Brazil
  between September 2016 and October 2018.
- What it contains: orders, order lines, payments, reviews, customers, sellers, products
  and geolocation.
- What it does **not** contain: website sessions, checkout page views, abandoned
  checkouts or any experiment assignment. Visitor-to-purchase conversion **cannot** be
  computed from it. The checkout experiment in this project is therefore simulated
  separately (see `docs/methodology.md`).

### Automatic download

```bash
uv run python -m marketplace_analytics download
```

This uses Kaggle's public download endpoint and, as of 2026-10-14, needs no credentials.
The archive's SHA-256 is compared with the value recorded in `config/settings.yaml`. A
mismatch is logged as a warning, and the data-quality checks then confirm that the
content is still valid.

### Manual download (if the automatic download fails)

1. Sign in at the Kaggle URL above and click **Download**.
2. Either extract the CSV files into `data/raw/`, or put the zip there as
   `data/raw/brazilian-ecommerce.zip` and run the `download` command, which extracts it.
3. Run `uv run python -m marketplace_analytics build`.

Files used by the warehouse (the geolocation file is downloaded but not used):

```
olist_customers_dataset.csv        olist_orders_dataset.csv
olist_order_items_dataset.csv      olist_products_dataset.csv
olist_order_payments_dataset.csv   olist_sellers_dataset.csv
olist_order_reviews_dataset.csv    product_category_name_translation.csv
```

## Tests without the real data

The test suite never needs the real data. `tests/fixtures/olist_fixture.py` writes a
tiny, hand-made, Olist-shaped dataset (a labelled test fixture, not real data) and
builds the full pipeline on it.
